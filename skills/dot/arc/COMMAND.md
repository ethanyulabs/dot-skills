# dot arc: drive the user's Arc browser in a named space

Subcommand of the `dot` skill; `SKILL_DIR` is the `dot` directory and `ARC_DIR` is `$SKILL_DIR/arc`, which holds this file. macOS only. Needs Arc (https://arc.net) and uv (https://docs.astral.sh/uv/): `scripts/darc.py` declares its one dependency inline (`websockets`), a few hundred KB on first run. Spaces and tabs are driven through Arc's own AppleScript dictionary; page interaction goes through the Chrome DevTools Protocol, which needs Arc started once with `--remote-debugging-port=9222` (`references/principles.md`, Step 0 says how; `selftest` prints the exact command). macOS asks once for permission to control Arc. Version 0.5.0.

Usage: `/dot arc <action> [args]` (Codex: `$dot arc …`), or plain language such as "在 byted 空间打开 …", "用 Arc 登录态抓一下这个页面", "在 Arc 里点一下那个按钮", "open this in Arc", "in the agent space". The user's Arc stays theirs: every command runs in the background and never switches the space or tab they are looking at unless they asked to watch (`--focus`) or to be shown (`--activate`). Arc itself raises a tab it just created, so `open` selects the user's tab again inside the same AppleScript (`restored: true`; a flicker at most). Several agents can run at once, each in its own session. The user's home `~/.dot/arc/` (`DOT_HOME` moves the `~/.dot` root) holds the default space (`config.json`), the sessions and every output.

## Actions

| Action | Invocation | What it does | Read |
|---|---|---|---|
| `selftest` | `darc selftest [--deep]` | checks osascript, Arc, the Automation permission, the DevTools port and websockets; prints the relaunch command when the port is closed; `--deep` also opens one websocket | `references/principles.md` |
| `spaces` / `tabs` | `darc spaces` / `darc tabs [--space S \| --all]` | the spaces of the front window (active one marked, configured default shown); the tabs of one space with id, title, URL, pinned or not | `references/spaces.md` |
| `open` | `darc open <url> [--space S] [--session N] [--focus] [--no-wait]` | a new tab with that URL in the space, bound to a DevTools target, saved as a session; silent by default | `references/spaces.md` |
| `attach` | `darc attach (--active \| --tab-id ID \| --url U) [--session N] [--target-id T]` | a session on a tab that is already open (the user's current tab, a logged-in page) | `references/spaces.md` |
| `goto` / `back` / `forward` / `reload` / `close` | `darc goto <url>`, `darc back`, `darc reload`, `darc close [--keep-tab]` | navigate the session's tab through AppleScript (no focus change); close the tab and forget the session | `references/spaces.md` |
| `sessions` | `darc sessions` | every session with its space, URL and whether its target is still alive | `references/spaces.md` |
| `snapshot` | `darc snapshot [--root SEL] [--depth N] [--boxes] [--max-chars N]` | the accessibility outline of the page with `[ref=eN]` on everything clickable or focusable | `references/interact.md` |
| `click` / `fill` / `press` / `wait` | `darc click <ref\|selector> [--double] [--button right]`, `darc fill <ref\|selector> <text> [--press Enter]` (text that starts with `-`: `darc fill e7 -- "-text"`), `darc press <key> [--target …]`, `darc wait --url GLOB \| --selector SEL \| --text T \| --ms N \| --load load\|domcontentloaded` | act on the page; every one takes `--snapshot` to return the fresh outline in the same call | `references/interact.md` |
| `screenshot` / `extract` / `eval` | `darc screenshot [--out PATH] [--full] [--target …] [--activate]`, `darc extract [--what text\|links\|html\|title] [--root SEL] [--out FILE]`, `darc eval <js> [--out FILE]` | see the page, read it as text, run JavaScript in it | `references/read.md` |
| `config` | `darc config show` / `config set space=NAME [port=N]` / `config unset KEY` | the default space and port in `~/.dot/arc/config.json`; `--space` on any command overrides the default without changing it | `references/principles.md`, Home directory |

Every command takes `--port`, `--session` (or `DOT_ARC_SESSION`), `--space`, `--timeout MS` and `--quiet`, prints one JSON line and exits 0 / 2 / 4 / 5 (`references/principles.md`, Output contract).

## Steps

1. **Orient.** Read `references/principles.md` and follow its Step 0: set `SKILL_DIR` and `ARC_DIR`, define `darc` as `uv run --script <ARC_DIR>/scripts/darc.py`, run `darc selftest`. If `checks.cdp` is false, the page commands (`snapshot`, `click`, `fill`, `press`, `wait`, `screenshot`, `extract`, `eval`) are unavailable until Arc is relaunched; the AppleScript commands (`spaces`, `tabs`, `open`, `attach`, `goto`, `back`, `forward`, `reload`, `close`, `sessions`, `config`) keep working, and `open` / `tabs` already return each tab's `title` and `url` (Arc's own tab title, read after the page loaded). So: if the request needs only those (open a page, read its title or address, navigate, close), finish it with them and say in the report that page commands were unavailable; otherwise give the user `relaunch.zh` and the `relaunch.shell` line as they are, do the AppleScript part if it helps, and stop there. If `checks.automation` is false, follow `references/troubleshooting.md`, Automation permission.
2. **Pick the space.** In this order: the space the user named ("在 X 空间" → `--space X`); the configured default (`selftest` prints it as `default_space`); otherwise run `darc spaces` and ask the user once which one, listing the titles. When the user says "以后都用 X" / "always use X", run `darc config set space=X` and say it is saved; a space named for one request is passed with `--space` and never saved.
3. **Get a session.** `darc open <url> --space S` for a new page, or `darc attach --active` when the user says "this page" / "这个页面" and is already on it. Copy `export_hint` into the shell before the next command (`export DOT_ARC_SESSION=<name>`); an agent whose shell resets between commands passes `--session <name>` on every command instead. A `--session NAME` you choose must be new (`SESSION_EXISTS` otherwise: another agent may be using it). One session per task; never open a second tab to recover from a stuck page.
4. **Work the page in a loop.** `darc snapshot` to see what is there, then `darc click e12` / `darc fill e7 "text" --press Enter` / `darc press Enter`, each with `--snapshot` so the next ref is never stale; `darc wait --url …` after a submit; `darc extract` when the user wants the content. `REF_STALE` means the page changed: take a new snapshot, do not guess. At most two blind retries of the same step; then `darc screenshot`, open the PNG with the Read tool, and decide or ask. Every interaction stays in the session's tab and space.
5. **Look before you report.** Any time the user asked to see the page, the page looks wrong, or the report makes a visual claim, run `darc screenshot` and open the file with the Read tool. `SCREENSHOT_NEEDS_FOREGROUND` means the tab is in the background and Chromium did not render it: read the page with `extract` / `eval` instead; add `--activate` only when the user agreed that Arc may flash to that tab for a moment (it switches back by itself). When page commands are unavailable (Step 1), this step is skipped and the report says so.
6. **Finish.** `darc close` unless the user wants the tab kept (`--keep-tab` forgets the session only). A coordinating agent that dispatched several sub-agents runs `darc sessions` and closes what they left. Report in Chinese with `assets/templates/report.zh-CN.md`.

Sensitive actions (paying, sending a message or mail, deleting, granting a permission, changing account settings) run only when the user named that action in this conversation; otherwise stop before the click and ask. Never type a password or code the user did not give in this conversation; when a page asks the user to sign in, say so and let them do it in Arc, then continue. Several agents at once: each uses its own session and, where possible, its own space; no `--focus`, no `--activate` without the user's say-so.

## Done when

- The user's goal on the page is reached, or the user knows exactly what blocks it (which step, which error code, what they can do).
- Every screenshot the report mentions was opened with the Read tool, and every statement about what the page shows comes from a snapshot, an extract or a screenshot of this run.
- The space and tab the user was looking at are the ones they are looking at now; `--focus` / `--activate` were used only on request.
- The session is closed, or the user asked to keep the tab; nothing was committed.
